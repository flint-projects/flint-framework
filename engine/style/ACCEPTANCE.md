## Stub and always-success review

No stubs or ignored inputs found; every `Style` field is used. Observed design points left unchanged because `tui`, `widgets` and the golden TUI depend on the output bytes, and an `unset` colour would need an API change:

- Top and bottom border rows are not painted. Side borders and content rows are.
- Setting only one of `foreground`/`background` emits both SGR colours, so the other becomes black, because `Color.init` doubles as "unset".
- `truncateCells`, `measure` and the joins pass through Flint's own SGR subset (`0/1/3/4m`, RGB `38;2`/`48;2`), so rendered blocks can be composed. Every other escape is replaced.
